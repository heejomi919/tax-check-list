# 조기환급시 체크리스트

세금계산서(건물등감가상각취득명세서)·견적서·송금내역을 거래처별로 자동 대조해주는 도구입니다.
설치 없이 파일을 더블클릭하면 바로 열리고, 인터넷 연결 없이도 동작합니다.

---

## 시작하는 법

1. `대한세무법인_조기환급체크리스트_공유용.html` 파일을 다운로드하세요.
2. 원하는 폴더(바탕화면 등)에 저장하세요.
3. 더블클릭하면 브라우저(크롬, 엣지 등)에서 바로 열립니다.

## 직원에게 공유할 때

**HTML 파일 하나만 보내면 됩니다.** 메일 첨부, 사내 공유 폴더, USB 무엇이든 됩니다.

사용법이 파일 안에 들어 있어서(맨 위 **📖 처음 쓰시는 분 — 사용법**) 이 README를 함께 보낼 필요가 없습니다.
받은 사람은 저장 후 더블클릭만 하면 되고, 설치나 로그인은 없습니다.

각자 입력한 내용은 **각자 컴퓨터에만** 남습니다(서로 안 보입니다). 같이 봐야 하는 자료는 엑셀로 내려받아 주고받으세요.

---

## 사용 순서

1. **거래처 정보** — 상호, 담당자, **연도, 조기환급 대상월**을 입력하세요. 관할세무서는 직접 적어도 되고, 아래 검색창에서 동네·세무서 이름으로 찾아 눌러 넣어도 됩니다.
2. **매출현황** — POS 자료를 보고 결제수단별 금액을 입력하세요. 사진(캡처)으로 받으셨다면, 숫자만 순서대로 한 줄씩 입력하고 "표에 적용"을 누르면 한 번에 채워집니다.
3. **건물등감가상각취득명세서** — 위하고에서 엑셀 파일로 변환해서 다운로드한 뒤 그대로 올리세요 (화면 캡처나 PDF는 자동으로 안 채워집니다). 카드를 펼쳐서 "자료 불러오기"로 업로드하거나 붙여넣기 하세요.
4. **견적서 내역** — 견적서 **사진·PDF를 올리면 판독 화면이 바로 열립니다.** 원본을 크게 보면서 거래처·일자·금액 세 칸만 채우면 표와 대사표에 즉시 반영됩니다. 엑셀 업로드·붙여넣기도 그대로 됩니다.
5. **송금내역** — 이체확인증도 같습니다. 사진·PDF를 올리면 판독 화면이 열리고, 세 칸만 채우면 됩니다.
6. **대사표** — 거래처별로 세금계산서·견적서·송금 금액이 자동으로 비교됩니다. 상태는 세 가지입니다.
   - ✅ **일치** — 데이터가 둘 이상 있고 금액이 같음
   - ⚠️ **확인필요** — 데이터가 둘 이상 있는데 금액이 다름
   - ⬜ **자료부족** — 아직 하나만 입력되어 비교할 게 없음
   - 첨부서류 칸에서 **계약서·견적서·입금증을 거래처별로 바로 첨부**할 수 있습니다. "＋"를 누르고 파일(사진·PDF)을 고르면 체크가 자동으로 켜지고 📎 링크가 생깁니다. 여러 장이면 계속 눌러서 추가하세요.
   - 비고도 여기서 남길 수 있습니다.
7. **자동 점검** — 입력한 날짜·금액만 보고 거래처별로 확인할 점을 찾아줍니다. 확인필요 거래처가 위로 올라옵니다.
8. 다 확인하셨으면 **엑셀로 다운로드**를 눌러 파일로 보관하세요. (대사표·자동 점검 결과까지 함께 저장됩니다)

## 자동 점검이 잡아주는 것

거래처별로 다음을 자동으로 찾아 "확인할 점"에 적어줍니다.

| 구분 | 예시 문구 |
|---|---|
| 자료 없음 | 세금계산서·송금내역이 아예 없는 거래처 |
| 미첨부/미확인 | 견적서·계약서를 아직 안 올렸거나 체크 안 한 거래처 |
| 금액 차이 | 세금계산서 ↔ 송금 차액 (잔금 미지급·분할지급 여부) |
| 금액 차이 | 세금계산서 ↔ 견적서 차액 (추가공사·변경계약 여부) |
| **공급시기** | 세금계산서 작성일이 **조기환급 대상월 밖** |
| **공급시기** | 송금일이 세금계산서일보다 **빠름** (선급금·중간지급조건부 확인) |
| **공급시기** | 마지막 송금일이 세금계산서일보다 30일 이상 늦음 (잔금 지급시기) |
| 서류 일자 | 견적서일이 세금계산서일보다 늦음 (앞뒤 순서 이상) |

### ⚠️ 자동 점검은 추정입니다
입력된 **날짜와 금액만** 보고 기계적으로 걸러낸 결과라 오탐이 있을 수 있습니다.
계약금·잔금 분할지급, 중간지급조건부 공사처럼 정상인데도 "확인필요"가 뜨는 경우가 많습니다.
반드시 원본 서류로 확인하시고, **공급시기 판단은 담당 세무사의 최종 검토를 거쳐주세요.**

### 날짜 점검을 받으려면 "연도"와 "대상월"을 먼저 넣어주세요
거래처 정보의 **연도**가 비어 있으면 `02-10`처럼 월·일만 있는 날짜는 해석할 수 없어 날짜 점검에서 빠집니다.
**조기환급 대상월**을 넣으면 "대상월 밖 세금계산서" 점검이 함께 돌아갑니다.

## 사진을 올렸을 때 — 판독 화면

견적서·이체확인증 사진(또는 PDF)을 올리면 **판독 화면이 자동으로 열립니다.**

- **왼쪽**: 원본 사진 (클릭하면 확대/축소, PDF는 그대로 보임)
- **오른쪽**: 거래처 · 일자 · 금액 세 칸 — 채우는 즉시 표와 대사표에 반영
- **세금계산서 상호에서 고르기**: 버튼을 한 번 누르면 거래처명이 세금계산서와 똑같이 맞춰집니다 (통장에 대표자 개인명이 찍혀 있어도 해결)
- **다음 첨부 ▶**: 여러 장을 연속으로 판독
- **Esc** 또는 "입력 완료"로 닫기

파일명에 날짜와 거래처가 들어 있으면(예: `견적서_6.23_혜성.jpg`) 그 두 칸은 미리 채워져 있습니다. 추측이니 원본과 대조해주세요.

### 🔍 사진에서 숫자 읽기 (자동 인식)

판독 화면의 **🔍 사진에서 숫자 읽기** 를 누르면 사진에서 숫자를 뽑아 후보로 보여줍니다.

| 읽는 것 | 어떻게 쓰이나 |
|---|---|
| **사업자등록번호** (3-2-5자리) | 취득명세서의 상호와 대조해 **거래처를 자동으로 맞춰줍니다** |
| **금액** (쉼표 있는 숫자) | 큰 금액이 위로 오게 후보 나열 — 눌러서 넣기 |
| **날짜** | 오래된 날짜가 위로 (이체확인증의 "조회기준일시"보다 실제 거래일이 먼저 오도록) |

**한글 상호는 읽지 않습니다.** 인식률이 낮아 아예 시도하지 않고, 대신 숫자로만 된 사업자등록번호를 읽어 상호를 맞춥니다. 금액도 쉼표가 있는 만원 이상 숫자만 후보로 올려 단가·수량·전화번호와 섞이지 않게 했습니다.

#### 실제로 인식 엔진을 돌려 확인한 결과

| 서류 | 사업자등록번호 | 금액 | 날짜 |
|---|---|---|---|
| **은행 이체확인증** | (해당 없음) | ✅ 26,226,750 정확 | ✅ 이체일 06-23 이 1순위 |
| **견적서** | ✅ 인식 → 상호 자동 매칭 | ✅ 합계 52,453,500 이 1순위 | ❌ **못 읽습니다** |

**견적서의 한글 날짜(`2026년 06월 23일`)는 읽지 못합니다.** 영어 인식 모델이 "년·월·일"을 숫자 쓰레기로 바꿔버려서(`202613 0609 2309`) 날짜를 뽑을 수 없습니다. 억지로 추측하면 틀린 날짜를 확신 있게 내놓게 되므로 **후보를 아예 보여주지 않습니다.** 날짜는 직접 입력해주세요. 은행 이체확인증은 날짜가 `2026/06/23` 형태라 정확히 읽힙니다.

#### ⚠️ 읽은 값은 반드시 원본과 대조하세요
기계가 사진에서 읽은 값이라 **틀릴 수 있습니다.** 그래서 곧바로 표에 넣지 않고 **후보로만** 보여주며, 왼쪽에 원본이 함께 떠 있으니 눌러 넣기 전에 대조해주세요.

#### 인터넷이 필요하고, 링크로 열면 동작하지 않습니다
글자 인식 프로그램을 인터넷에서 받아오기 때문입니다.
- **HTML 파일로 열었을 때 + 인터넷 연결** → 동작합니다
- **claude.ai 링크로 열었을 때** → 보안정책으로 프로그램을 받아올 수 없어 안내 문구가 뜹니다. 이때는 직접 입력하시면 됩니다.

## 꼭 알아두셔야 할 점

### ⚠️ 거래처 이름은 정확히 똑같이 입력해야 매칭됩니다
세금계산서엔 회사명(예: 우리종합주방)이, 통장엔 대표자 개인명(예: 유상진)이 찍히는 경우가 많습니다.
**이 도구는 이름이 다르면 자동으로 묶어주지 않습니다.** 같은 거래처라면 세금계산서·견적서·송금내역 모두 **같은 이름**으로 통일해서 입력해주세요. 그렇지 않으면 대사표에서 서로 다른 거래처로 잡혀서 매칭이 안 됩니다.

### 저장은 이 컴퓨터의 이 브라우저에만 남습니다
"저장" 버튼은 브라우저 내부 저장공간(로컬 스토리지)에 남는 것이라, 다른 컴퓨터나 다른 브라우저에서는 안 보입니다. 여러 사람이 같이 봐야 하는 자료는 **엑셀로 다운로드**해서 전달해주세요.

### 자동으로 채워진 값은 참고용입니다
파일명에서 추측한 날짜·거래처, 업로드로 불러온 금액 모두 **한 번씩 원본과 대조**한 뒤 신고에 반영해주세요.

### 첨부한 파일은 브라우저를 닫으면 링크가 끊깁니다
📎 링크는 지금 열어둔 이 화면에서만 유효합니다(브라우저 임시 링크). 새로 열면 다시 첨부해야 하니,
검토가 끝나면 **엑셀로 다운로드**해서 기록을 남기고, 원본 파일은 아래 폴더 규칙대로 보관해주세요.

### 처음 열 때는 인터넷이 필요합니다
엑셀 읽기 기능과 글꼴을 파일 안에 담아뒀지만, 글꼴(Pretendard)은 인터넷에서 불러옵니다. 인터넷이 안 되면 자동으로 기본 글꼴로 보이니 오류는 아닙니다.

## 보관 폴더와 파일명 규칙

📎 첨부는 창을 닫으면 끊기므로 **원본 사진을 폴더에 남기고, 도구에서 받은 엑셀을 같은 폴더에** 두세요. 다음에 이어서 볼 때 이 폴더만 있으면 됩니다.

```
조기환급/
└ 2026-07_놀pc방당하동점/          ← 대상월_거래처 (숫자로 시작해 자동 정렬)
  ├ 1_취득명세서/   위하고에서 받은 엑셀 원본
  ├ 2_견적서/       견적서_6.23_혜성.jpg
  ├ 3_송금증/       이체확인증_6.23_혜성.pdf
  ├ 4_계약서/       계약서_혜성.pdf
  └ 조기환급체크_놀pc방당하동점_2026년_1기예정_(7월).xlsx   ← 도구에서 받은 엑셀
```

폴더명을 `2026-07_거래처`로 시작하면 여러 건이 쌓여도 **월별로 자동 정렬**됩니다. 도구에서 내려받는 엑셀 파일명은 거래처·연도·기간이 자동으로 붙으니 그대로 쓰시면 됩니다.

### 파일명은 `서류종류_월.일_거래처` 순서로

이 순서로 적으면 사진을 올릴 때 **날짜와 거래처가 미리 채워집니다.**

| 파일명 | 인식 결과 |
|---|---|
| `견적서_6.23_혜성.jpg` | 날짜 2026-06-23 · 거래처 혜성 |
| `이체확인증_7.24_우리종합주방.pdf` | 날짜 2026-07-24 · 거래처 우리종합주방 |
| `혜성_2026.06.23.jpg` | 날짜 2026-06-23 · 거래처 혜성 (연월일을 다 써도 됩니다) |
| `KakaoTalk_20260623_143512.jpg` | 날짜 2026-06-23 (휴대폰·카톡 기본 파일명도 날짜를 알아냅니다) |
| `혜성_견적서.jpg` | 거래처 혜성 · 날짜는 직접 입력 |

- **거래처명은 세금계산서 상호로** 쓰세요 (통장에 찍힌 대표자 개인명이 아니라 `혜성`).
- 월·일만 쓸 때는 거래처 정보의 **연도**를 채워둬야 연도가 붙습니다.
- 추측이므로 판독 화면에서 **원본과 한 번 대조**해주세요.

## 자주 묻는 질문

**Q. 대사표에 "확인필요"가 떴는데 잘못된 건가요?**
아니요. 계약금·잔금처럼 나눠서 지급한 경우엔 정상적으로 차이가 날 수 있습니다. 참고해서 판단해주시고, 필요하면 비고란에 이유를 적어두세요.

**Q. 세금계산서합계표나 다른 형식의 엑셀도 되나요?**
"건물등감가상각취득명세서" 항목은 그 형식 전용입니다. 다른 형식의 자료가 필요하시면 담당자에게 문의해주세요.

**Q. 저장했던 게 안 보여요.**
브라우저를 바꿔서 열었거나, 다른 컴퓨터에서 여신 건 아닌지 확인해주세요. 저장 내용은 컴퓨터+브라우저 조합별로 따로 남습니다.
