국세청 제출용이 아닙니다.

## 받아서 쓰는 법

1. 위 목록에서 `대한세무법인_조기환급체크리스트_공유용.html` 을 누르고 **Download raw file** 로 내려받으세요.
2. 바탕화면 등에 저장하고 **더블클릭**하면 브라우저에서 바로 열립니다. 설치·로그인 없습니다.
3. **사용법은 도구 안에 있습니다** — 화면 맨 위 **📖 처음 쓰시는 분 — 사용법** 을 눌러보세요.

직원에게 줄 때도 이 **HTML 파일 하나만** 보내면 됩니다(메일·공유폴더·USB 무엇이든).

## 꼭 알아두기

- **거래처명은 세금계산서 상호로 통일하세요.** 통장에 대표자 개인명이 찍혀 있어도 상호로 적어야 대사표에서 묶입니다. 판독 화면의 "세금계산서 상호에서 고르기" 버튼을 쓰면 실수가 없습니다.
- **📎 첨부는 창을 닫으면 링크가 끊깁니다.** 검토가 끝나면 엑셀로 내려받아 기록을 남기고, 원본 사진은 폴더에 따로 보관하세요.
- **저장은 각자 컴퓨터의 그 브라우저에만** 남습니다(서로 안 보입니다). 같이 볼 자료는 엑셀로 주고받으세요.
- **자동 점검은 추정입니다.** 계약금·잔금 분할지급이나 중간지급조건부 공사처럼 정상인데도 "확인필요"가 뜹니다. 반드시 원본과 대조하세요.
- **연도와 조기환급 대상월**을 먼저 넣어야 날짜 점검이 돌아갑니다.

## 참고 — 사진에서 숫자 읽기는 어디까지 되나

판독 화면의 **🔍 사진에서 숫자 읽기**는 **숫자만** 읽습니다. 한글 상호는 인식률이 낮아 아예 시도하지 않고, 대신 사업자등록번호를 읽어 취득명세서의 상호와 맞춥니다.

실제 인식 엔진을 돌려 확인한 결과입니다.

| 서류 | 사업자등록번호 | 금액 | 날짜 |
|---|---|---|---|
| 은행 이체확인증 | (해당 없음) | ✅ 정확 | ✅ 이체일이 1순위 |
| 견적서 | ✅ 인식 → 상호 자동 매칭 | ✅ 합계가 1순위 | ❌ **못 읽습니다** |

견적서의 한글 날짜(`2026년 06월 23일`)는 영어 인식 모델이 "년·월·일"을 숫자 쓰레기로 바꿔버려 복원할 수 없습니다. 억지로 추측하면 틀린 날짜를 확신 있게 내놓게 되므로 **후보를 아예 보여주지 않습니다** — 날짜는 직접 입력해주세요.
