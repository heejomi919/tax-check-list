# 조기환급시 체크리스트

세금계산서(건물등감가상각취득명세서)·견적서·송금내역을 거래처별로 자동 대조해주는 도구입니다.
설치 없이 파일을 더블클릭하면 바로 열리고, 인터넷 연결 없이도 동작합니다.

---

## 시작하는 법

1. `대한세무법인_조기환급체크리스트_공유용.html` 파일을 다운로드하세요.
2. 원하는 폴더(바탕화면 등)에 저장하세요.
3. 더블클릭하면 브라우저(크롬, 엣지 등)에서 바로 열립니다.

---

## 사용 순서

1. **거래처 정보** — 상호, 담당자, 연도, 기간을 입력하세요. 관할세무서를 모르면 아래 검색창에 동네 이름을 넣어보세요 (예: 분당구, 야탑동).
2. **매출현황** — POS 자료를 보고 결제수단별 금액을 입력하세요. 사진(캡처)으로 받으셨다면, 숫자만 순서대로 한 줄씩 입력하고 "표에 적용"을 누르면 한 번에 채워집니다.
3. **건물등감가상각취득명세서** — 위하고에서 엑셀 파일로 변환해서 다운로드한 뒤 그대로 올리세요 (화면 캡처나 PDF는 자동으로 안 채워집니다). 카드를 펼쳐서 "자료 불러오기"로 업로드하거나 붙여넣기 하세요.
4. **견적서 현황** — 견적서 **사진·PDF를 올리면 판독 화면이 바로 열립니다.** 원본을 크게 보면서 거래처·일자·금액 세 칸만 채우면 표와 검토조서에 즉시 반영됩니다. 엑셀 업로드·붙여넣기도 그대로 됩니다.
5. **송금내역** — 이체확인증도 같습니다. 사진·PDF를 올리면 판독 화면이 열리고, 세 칸만 채우면 됩니다.
6. **대사표** — 거래처별로 세금계산서·견적서·송금 금액이 자동으로 비교됩니다. 상태는 세 가지입니다.
   - ✅ **일치** — 데이터가 둘 이상 있고 금액이 같음
   - ⚠️ **확인필요** — 데이터가 둘 이상 있는데 금액이 다름
   - ⬜ **자료부족** — 아직 하나만 입력되어 비교할 게 없음
   - 첨부서류 칸에서 **계약서·견적서·입금증을 거래처별로 바로 첨부**할 수 있습니다. "＋"를 누르고 파일(사진·PDF)을 고르면 체크가 자동으로 켜지고 📎 링크가 생깁니다. 여러 장이면 계속 눌러서 추가하세요.
   - 비고도 여기서 남길 수 있습니다.
7. **자동 점검** — 입력한 날짜·금액만 보고 거래처별로 확인할 점을 찾아줍니다. 확인필요 거래처가 위로 올라옵니다.
8. **거래처별 검토조서** — 거래처 한 곳당 한 장으로 계약서·견적서·세금계산서·송금을 모아 보여줍니다. **검토 결론**(○ 신고가능 / △ 자료보완 / ✗ 제외)과 근거를 여기서 적으세요.
9. 다 확인하셨으면 **엑셀로 다운로드**를 눌러 파일로 보관하세요. (대사표·자동 점검·검토조서까지 함께 저장됩니다)

---

## 세무사님께 드릴 때 — 검토조서만 인쇄

7번 카드의 **"🖨 조서만 인쇄 (거래처별 1장)"** 을 누르면 입력 화면은 빠지고 **검토조서만 거래처별로 한 장씩** 인쇄됩니다. PDF로 저장하셔도 됩니다.

조서 한 장에 들어가는 내용입니다.

| 항목 | 내용 |
|---|---|
| 머리 | 상호 · 사업자등록번호 · **검토 결론** |
| 표 | 계약서 / 견적서 / 세금계산서 / 송금 — 금액, 일자, 첨부 유무(📎 개수) |
| 자동 점검 | 그 거래처에서 확인할 점 |
| 담당자 근거 | 결론을 그렇게 낸 이유 |
| 서명 | 담당자 / 세무사 확인란 |

**계약금액과 계약일은 조서에서 직접 입력**합니다(계약서는 엑셀로 받는 자료가 아니라서요). 적어두면 자동 점검이 계약금액 ↔ 세금계산서 차액도 함께 봐줍니다.

---

## 자동 점검이 잡아주는 것

거래처별로 다음을 자동으로 찾아 "확인할 점"에 적어줍니다.

| 구분 | 예시 문구 |
|---|---|
| 자료 없음 | 세금계산서·송금내역이 아예 없는 거래처 |
| 미첨부/미확인 | 견적서·계약서를 아직 안 올렸거나 체크 안 한 거래처 |
| 금액 차이 | 세금계산서 ↔ 송금 차액 (잔금 미지급·분할지급 여부) |
| 금액 차이 | 세금계산서 ↔ 견적서 차액 (추가공사·변경계약 여부) |
| 금액 차이 | **계약서 ↔ 세금계산서** 차액 (조서에 계약금액을 적은 경우만) |
| **공급시기** | 세금계산서 작성일이 **조기환급 대상월 밖** |
| **공급시기** | 송금일이 세금계산서일보다 **빠름** (선급금·중간지급조건부 확인) |
| **공급시기** | 마지막 송금일이 세금계산서일보다 30일 이상 늦음 (잔금 지급시기) |
| 서류 일자 | 견적서일이 세금계산서일보다 늦음 (앞뒤 순서 이상) |

### ⚠️ 자동 점검은 추정입니다
입력된 **날짜와 금액만** 보고 기계적으로 걸러낸 결과라 오탐이 있을 수 있습니다.
계약금·잔금 분할지급, 중간지급조건부 공사처럼 정상인데도 "확인필요"가 뜨는 경우가 많습니다.
반드시 원본 서류로 확인하시고, **공급시기 판단은 담당 세무사의 최종 검토를 거쳐주세요.**

### 날짜 점검을 받으려면 "연도"와 "대상월"을 먼저 넣어주세요
거래처 정보의 **연도**가 비어 있으면 `02-10`처럼 월·일만 있는 날짜는 해석할 수 없어 날짜 점검에서 빠집니다.
**조기환급 대상월**을 넣으면 "대상월 밖 세금계산서" 점검이 함께 돌아갑니다.

## 꼭 알아두셔야 할 점

## 사진을 올렸을 때 — 판독 화면

견적서·이체확인증 사진(또는 PDF)을 올리면 **판독 화면이 자동으로 열립니다.**

- **왼쪽**: 원본 사진 (클릭하면 확대/축소, PDF는 그대로 보임)
- **오른쪽**: 거래처 · 일자 · 금액 세 칸 — 채우는 즉시 표와 검토조서에 반영
- **세금계산서 상호에서 고르기**: 버튼을 한 번 누르면 거래처명이 세금계산서와 똑같이 맞춰집니다 (통장에 대표자 개인명이 찍혀 있어도 해결)
- **다음 첨부 ▶**: 여러 장을 연속으로 판독
- **Esc** 또는 "입력 완료"로 닫기

파일명에 날짜와 거래처가 들어 있으면(예: `견적서_6.23_혜성.jpg`) 그 두 칸은 미리 채워져 있습니다. 추측이니 원본과 대조해주세요.

### 사진의 숫자를 자동으로 읽어주지는 않습니다
글자 인식(OCR)은 넣지 않았습니다. 한글 견적서 인식률이 실무 수준이 아니고, **금액 한 자리가 틀리면 안 읽은 것보다 위험**하기 때문입니다.
판독 화면은 그 대신 "원본을 크게 보면서 최소한만 입력"하도록 만든 것입니다.
사진을 담당자에게 보내주시면 판독해서 붙여넣기용 표로 정리해 드릴 수도 있습니다.

## 꼭 알아두셔야 할 점 (계속)

### ⚠️ 거래처 이름은 정확히 똑같이 입력해야 매칭됩니다
세금계산서엔 회사명(예: 우리종합주방)이, 통장엔 대표자 개인명(예: 유상진)이 찍히는 경우가 많습니다.
**이 도구는 이름이 다르면 자동으로 묶어주지 않습니다.** 같은 거래처라면 세금계산서·견적서·송금내역 모두 **같은 이름**으로 통일해서 입력해주세요. 그렇지 않으면 대사표에서 서로 다른 거래처로 잡혀서 매칭이 안 됩니다.

### 저장은 이 컴퓨터의 이 브라우저에만 남습니다
"저장" 버튼은 브라우저 내부 저장공간(로컬 스토리지)에 남는 것이라, 다른 컴퓨터나 다른 브라우저에서는 안 보입니다. 여러 사람이 같이 봐야 하는 자료는 **엑셀로 다운로드**해서 전달해주세요.

### 자동으로 채워진 값은 참고용입니다
파일명에서 추측한 날짜·거래처, 업로드로 불러온 금액 모두 **한 번씩 원본과 대조**한 뒤 신고에 반영해주세요.

### 첨부한 파일은 브라우저를 닫으면 링크가 끊깁니다
📎 링크는 지금 열어둔 이 화면에서만 유효합니다(브라우저 임시 링크). 새로 열면 다시 첨부해야 하니,
검토가 끝나면 **엑셀로 다운로드**해서 파일명 기록을 남기고, 원본 파일은 거래처별 폴더에 따로 보관해주세요.

### 처음 열 때는 인터넷이 필요합니다
엑셀 읽기 기능과 글꼴을 파일 안에 담아뒀지만, 글꼴(Pretendard)은 인터넷에서 불러옵니다. 인터넷이 안 되면 자동으로 기본 글꼴로 보이니 오류는 아닙니다.

## 자주 묻는 질문

**Q. 대사표에 "확인필요"가 떴는데 잘못된 건가요?**
아니요. 계약금·잔금처럼 나눠서 지급한 경우엔 정상적으로 차이가 날 수 있습니다. 참고해서 판단해주시고, 필요하면 비고란에 이유를 적어두세요.

**Q. 세금계산서합계표나 다른 형식의 엑셀도 되나요?**
"건물등감가상각취득명세서" 항목은 그 형식 전용입니다. 다른 형식의 자료가 필요하시면 담당자에게 문의해주세요.

**Q. 저장했던 게 안 보여요.**
브라우저를 바꿔서 열었거나, 다른 컴퓨터에서 여신 건 아닌지 확인해주세요. 저장 내용은 컴퓨터+브라우저 조합별로 따로 남습니다.
